# DOCXLS · 静态模板

> 只收集几个方便好用的静态生成器模板。

这里是一个轻量的静态模板集合，专注于收录**开箱即用、配置简单、适合快速起步**的静态站点生成器模板。无论你是想搭建个人博客、项目文档，还是产品落地页，都能在这里找到顺手的选择。

我们不做大而全的模板仓库，只保留经过筛选、维护友好、上手成本低的几个常用模板，帮你跳过繁琐的初始化配置，直接进入内容创作。

**主题：静态模板 · 模板集合**

## 🎯 我们关注什么

- **开箱即用**：克隆即可运行，不折腾环境
- **配置简单**：少量配置项，默认值合理
- **维护友好**：依赖精简，升级路径清晰
- **快速起步**：从零到上线，几分钟搞定

## 🧩 适合的场景

| 场景 | 说明 |
| --- | --- |
| ✍️ 个人博客 | 写作优先，专注内容而非配置 |
| 📚 项目文档 | 结构清晰，支持搜索与侧边导航 |
| 🚀 产品落地页 | 轻量快速，适合营销与展示 |
| 🗂️ 知识库 / 笔记 | 静态输出，易于托管与备份 |

## 🛠️ 使用方式

1. 在仓库列表中选择合适的模板
2. Fork 或使用模板创建自己的仓库
3. 修改配置文件与内容
4. 推送到托管平台（GitHub Pages、Netlify、Vercel 等）即可上线

## 🌱 收录标准

- 上手成本低，文档清晰
- 依赖少，构建速度快
- 有明确的维护者与更新记录
- 不收录大而全、配置复杂的模板仓库
